### A Beginner-Friendly Python Project

## 📖 About the Project

**Multi-Utility Toolkit** combines several everyday utilities in one interactive Python program. Choose an option from the menu to explore Python's standard library and practise fundamental programming concepts.

## ✨ Features

| Option | Feature | Description |
|:---:|---|---|
| 1 | 🕒 Date & Time Operations | Display the current date and time, compare two dates, format dates, use a stopwatch, and run a countdown |
| 2 | 🧮 Mathematical Operations | Calculate factorials and compound interest, perform sine/cosine calculations, and calculate a circle's area |
| 3 | 🎲 Random Data Generation | Generate a random number, random list, password, and six-digit OTP |
| 4 | 🆔 UUID Generator | Create a unique identifier with Python's `uuid` module |
| 5 | 📁 File Operations | Create, write, read, and append to files |
| 6 | 🔎 Explore Module Attributes | Inspect module attributes using `dir()` |
| 7 | 🚪 Exit | Exit the toolkit |

## 🛠️ Built With

- **Language:** Python
- **Standard library:** `datetime`, `time`, `math`, `random`, `string`, `uuid`, `os`
- **Concepts:** loops, conditional statements, user input, date/time operations, mathematics, random generation, file handling, and module exploration

## 🚀 Getting Started

### Prerequisites

- Python installed on your computer
- A terminal or Python editor such as IDLE or VS Code

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Open the project folder

```bash
cd YOUR-REPOSITORY
```

### 3. Run the program

```bash
python project7.py
```

On Windows, you can also try:

```bash

```
